PENTING:
Versi ini adalah prototipe statis. Data disimpan di localStorage browser masing-masing perangkat. Jadi chat, foto, VN, turnamen, konfirmasi hadir, jadwal, dan rapor BELUM tersinkron antar-HP dan bukan layanan real-time. Akun admin yang tertulis di HTML juga tidak aman untuk website publik. Untuk fitur sungguhan perlu backend (misalnya Firebase/Supabase), autentikasi, database, upload media, aturan akses admin/pemain, dan notifikasi web push yang memerlukan izin pengguna serta konfigurasi HTTPS. Jangan mengunggah password admin yang sama ke website publik.
Untuk GitHub Pages: unggah kedua file di root repository, lalu Settings > Pages > Deploy from a branch > main > /(root) > Save.
